# Aplicación conmemorativa CECyTEJ - 30 años

## Requisitos
- Python 3.9 o superior

## Instalación
```bash
pip install flask
python app.py
```
Abre en el navegador: http://127.0.0.1:5000

## Estructura
- app.py: servidor Flask y rutas
- templates/: páginas HTML
- static/css/estilos.css: diseño adaptable a celular y computadora

Los testimonios, fechas de eventos, fotografías y logros específicos están preparados como espacios editables para incorporar información confirmada por el plantel.
